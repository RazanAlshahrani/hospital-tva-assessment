# Hospital TVA Assessment

## Overview
This university group assignment uses a Threat-Vulnerability-Asset (TVA) matrix to examine cybersecurity threats in an SMC Hospitals academic scenario.

The report ranks critical IT assets, maps threats to those assets, assigns qualitative impact ratings, and identifies relevant security safeguards.

## Assets Assessed
- Patient database.
- Electronic Medical Records (EMR) system.
- Internal network.
- Medical devices.

## Threats Considered
- Ransomware.
- Data breaches.
- Insider threats.
- Internet of Medical Things (IoMT) device hijacking.
- Denial-of-service attacks.

## Assessment Contents
- A color-coded TVA matrix.
- Impact ratings: Extreme, High, Moderate, and Low.
- Explanations supporting the threat–asset impact ratings.
- Security safeguards mapped to the threat–asset combinations.

## Safeguards Discussed
Examples include firewalls, intrusion detection and prevention, multi-factor authentication, encryption, backups, access controls, network segmentation, and security awareness training.

## Academic Context
This report was completed as university group coursework. Its ratings and assumptions belong to the academic scenario and do not represent a verified assessment of the hospital's actual security posture.
